📚 学習ポイント

このレッスンで学べること:

  • セッション管理: セッション ID をクッキーに、データをサーバーに保存
  • セキュリティ: ユーザーデータがクライアントに露出しない
  • 認証: ログイン・ログアウトの実装
  • データ管理: セッションに任意のデータを保存・取得

🔍 確認してみよう:

  • 開発者ツール（F12）→ Application → Cookies で sessionId を確認
  • HttpOnly 属性が設定されているため JavaScript から読み取れない
  • Network タブでサーバーとのやり取りを確認
  • ログアウト後にセッション ID が削除されることを確認
