💡 重要なポイント:

📚 学習ポイント

このレッスンで学べること:

  • クッキーの基本: クッキーはサーバーからブラウザに送信される小さなデータ
  • 自動送信: ブラウザは自動的にクッキーを同じサーバーに送り返す
  • 属性: MaxAge, HttpOnly, Secure, SameSite などの重要な属性
  • 制限: 1つのクッキーは約 4KB まで、ドメインごとに制限あり

🔍 確認してみよう:

  • F12 キーを押して開発者ツールを開く
  • Application タブ → Storage → Cookies → localhost:3001
  • Network タブ → リクエストを選択 → Headers → Response Headers の Set-Cookie
  • Console タブ → document.cookie を実行
