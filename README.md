# Cookie セッション管理カリキュラム

クッキーベースのセッション管理を基礎から実践まで学べる包括的なカリキュラムです。

## 📚 カリキュラム概要

このカリキュラムでは、Web アプリケーションにおけるセッション管理の基礎から応用まで、段階的に学習します。各レッスンでは実際に動作するコード例を用いて、技術的原理、メリット・デメリット、ユースケースを解説します。

## 🎯 学習目標

- クッキーとセッションの基本的な仕組みを理解する
- セキュアなセッション管理の実装方法を習得する
- JWT を含む様々なセッション管理手法を比較検討できるようになる
- 実際のプロダクション環境で使える実装パターンを身につける

## 🏗️ 全体像

### セッション管理とは？

セッション管理は、ステートレスな HTTP プロトコル上で、ユーザーの状態を維持するための技術です。

```
┌─────────────┐                    ┌─────────────┐
│   Browser   │                    │   Server    │
│             │                    │             │
│  ┌───────┐  │  ① Login Request   │  ┌───────┐  │
│  │Cookie │  │ ──────────────────>│  │Session│  │
│  │Store  │  │                    │  │Store  │  │
│  └───────┘  │  ② Set-Cookie      │  └───────┘  │
│             │ <──────────────────│             │
│             │                    │             │
│             │  ③ Request + Cookie│             │
│             │ ──────────────────>│             │
│             │                    │             │
│             │  ④ Response        │             │
│             │ <──────────────────│             │
└─────────────┘                    └─────────────┘
```

### 主要な実装方式の比較

| 方式 | データの保存場所 | セキュリティ | スケーラビリティ | 複雑さ |
|------|-----------------|-------------|----------------|--------|
| **クッキーセッション** | クライアント（暗号化） | 高（適切な実装で） | 高 | 中 |
| **サーバーセッション** | サーバー（メモリ/DB） | 高 | 中～低 | 中 |
| **JWT** | クライアント（署名付き） | 中～高 | 高 | 低～中 |
| **ハイブリッド** | 両方 | 最高 | 中 | 高 |

## 📊 各手法の比較表

### クッキーセッション vs サーバーセッション vs JWT

| 項目 | クッキーセッション | サーバーセッション | JWT |
|------|-------------------|-------------------|-----|
| **データサイズ制限** | 4KB 程度 | 制限なし | 推奨 8KB 以下 |
| **サーバーメモリ** | 不要 | 必要 | 不要 |
| **データベース** | 不要 | 推奨 | 不要 |
| **即座の無効化** | 困難 | 容易 | 困難 |
| **水平スケール** | 容易 | やや困難 | 容易 |
| **セキュリティ** | 高（暗号化必須） | 高 | 中～高 |
| **実装の複雑さ** | 中 | 中 | 低～中 |
| **パフォーマンス** | 高 | 中 | 高 |

## 🔐 セキュリティの重要性

セッション管理はアプリケーションのセキュリティの要です。このカリキュラムでは、以下のセキュリティトピックをカバーします：

- **暗号化** - データの機密性
- **署名** - データの完全性
- **CSRF 対策** - Cross-Site Request Forgery
- **XSS 対策** - Cross-Site Scripting
- **セッション固定攻撃** - Session Fixation
- **セッションハイジャック** - Session Hijacking
